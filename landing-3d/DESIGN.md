# DESIGN.md — «Нить»

## 1. Визуальная вселенная

«Marjon» по-узбекски — бусы. Это и есть метафора продукта: модули ресторана — **бусины**, Marjon — **нить**, которая собирает их в одно украшение.

Вся страница — одна непрерывная 3D-сцена из девяти объектов: восемь перламутровых бусин (по числу модулей) и светящаяся мятная нить. Больше ничего в кадре нет. Сюжет скролла — судьба этой нити: она цела → рвётся → продевается заново → замыкается в кольцо → становится орнаментом → стягивается в одну жемчужину.

Настроение: тёмная ювелирная витрина. Медленно, гладко, дорого. Никаких резких движений — всё через lerp и scrub.

## 3. Шрифты

- **Unbounded** (variable, 400–800) — выразительный. Только заголовки, цифры-гиганты и номера глав.
- **Onest** (variable, 400–600) — нейтральный, шрифт бренда. Весь текст, UI, подписи. Цифры — `tabular-nums`.

Оба с кириллицей и латиницей (uz). Моноширинный шрифт сознательно убран: два семейства, не три.

## 6. Движение

- Один рендер-цикл на `gsap.ticker`; Lenis получает `raf` оттуда же.
- Один мастер-таймлайн (`paused`), его `time` ведёт скролл со сглаживанием. Он двигает камеру, позиции и материалы бусин, прорисовку нити и uniform-ы шейдеров (фон, частицы, постобработка).
- Заголовки: SplitText, маска по строкам, `power4.out`, шаг 0.03–0.06 с.
- UI-карточки: `y 40 → 0`, `opacity`, `expo.out`. Счётчики: 1.6 с, `power2.out`.
- Хроматическая аберрация зависит от скорости скролла.

## 7. Производительность и фолбэки

- `pixelRatio = min(devicePixelRatio, 2)`, на мобильных 1.5.
- Постобработка: bloom (на мобильных в половину силы) → виньетка + аберрация → OutputPass → зерно.
- Рендер останавливается, когда сцена закрыта бумажным блоком или вкладка скрыта.
- Слабое устройство (нет WebGL, ≤2 ядер, ≤2 ГБ памяти, Save-Data) → статичный постер `poster.jpg` вместо 3D.
- `prefers-reduced-motion` → постер, без Lenis и scrub, весь контент виден сразу.
- Моделей и текстур нет: всё процедурное, грузить нечего, Draco не нужен.
